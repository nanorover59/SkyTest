# SkyTest
Sky render and shader test activities:
* Draw geometry to a low resolution `GpuTexture` to get a pixel art effect more consistent with Minecraft graphics
* Render custom geometry with a simple directional light shader
* Render a sphere with lighting using a fragment shader

Currently following the tutorial: https://bgolus.medium.com/rendering-a-sphere-on-a-quad-13c92025570c#aa33
